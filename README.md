# SidCom Marketplace Web App\n\nThis is a web application for SidCom Marketplace built with Next.js 14.\n\n## Features\n- Next.js 14 (App Router)\n- TypeScript\n- Tailwind CSS\n- ShadCN UI\n- Firebase backend\n- i18n support (Arabic, French, English with RTL support)\n- Authentication\n- Product management\n- Seller dashboard\n\n## Project Structure\n\n````\n/\n├── app/  \n│   ├── page.tsx  \n│   ├── layout.tsx  \n├── components/  \n│   ├── Header.tsx  \n│   ├── Footer.tsx  \n│   └── ProductCard.tsx  \n├── firebase/  \n│   └── config.ts  \n├── i18n/  \n│   ├── en.json  \n│   ├── fr.json  \n│   └── ar.json  \n├── styles/  \n│   └── globals.css  \n└── package.json  \n````\n\n## Getting Started\n1. Clone the repository\n2. Install dependencies: `npm install`\n3. Run the development server: `npm run dev`\n\n## Configuration\n### Firebase\n1. Set up Firebase project\n2. Add your configuration to `firebase/config.ts`\n\n### i18n\n1. Add translations to the appropriate files in the `i18n/` folder.
